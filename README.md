# SUPER SWING

절차 생성되는 로우폴리 도심에서 로프 스윙, 타이밍 사격, 무작위 장비 조합을 결합한 1인칭 3D 로그라이크 스코어 액션 프로토타입입니다. 별도의 3D 모델 없이 Three.js 기본 도형과 Rapier 물리로 제작했습니다.

## 웹에서 플레이

[GitHub Pages에서 SUPER SWING 실행하기](https://seasun621.github.io/Hackathon/)

화면을 클릭하고 모드 카드를 고른 뒤, 카드 중앙에 나타나는 확인창에서 출격을 확정하면 시작됩니다. 데스크톱은 키보드·마우스, 휴대폰은 화면 양쪽의 전용 터치 조작을 사용합니다.

## 게임 모드

- `타임어택`: 전투·아이템 없이 90초 동안 폭탄 파괴 점수를 겨룹니다. 결과 화면 오른쪽 개인 랭킹은 점수순으로 정렬됩니다.
- `전투`: 아이템을 조합하며 10개 스테이지의 드론·강습 드론·골렘 편대를 돌파합니다. 스테이지 10의 목표 점수를 채우면 전용 엔딩이 재생됩니다. 개인 랭킹은 최고 도달 스테이지를 먼저, 같은 스테이지에서는 점수를 비교합니다.
- `무한 연습`: 타임어택과 같은 순수 스윙·폭탄 사냥 규칙을 시간제한 없이 연습합니다. 종료 압박과 랭킹 기록은 없습니다.

개인 랭킹은 현재 기기의 브라우저에 모드별로 저장되며, 각 결과 화면 오른쪽에서 확인할 수 있습니다.

## 조작

- 마우스 이동: 시점 및 조준
- 왼쪽 버튼 누르기: 노란 원으로 예고된 보정 앵커로 로프 발사·교체, 유지하는 동안 로프 권취 가속
- 왼쪽 버튼 놓기: 누적된 스윙 속도와 릴리스 보조를 유지하며 로프 해제
- 오른쪽 버튼 누르기: 현재 주무기 연속 사격
- W/A/S/D: 공중 방향 보정, 도로·옥상에서 빠른 걸음 수준의 지상 달리기
- Q: 현재 스태미나를 모두 사용해 시선 방향으로 직선 부스트
- Space: Q와 같은 가스를 전부 소비해 위로 솟구치는 수직 점프 부스터
- R: 현재 판 재시작
- Esc: 일시 정지

### 모바일 조작

- 왼쪽 조이스틱: 공중 방향 보정 및 지상 이동
- 오른쪽 빈 화면 드래그: 시점 및 조준
- `TETHER` 누르고 유지: 로프 발사·권취, 놓으면 로프 해제
- `FIRE` 누르고 유지: 주무기 연속 사격
- `BOOST`: 보유 스태미나를 사용한 직선 부스트
- `JUMP`: `BOOST`와 같은 가스를 모두 사용해 위로 솟구치는 수직 부스트
- `Ⅱ`: 일시 정지

모바일 조작부와 모바일 안내는 터치가 가능한 휴대폰형 포인터 환경에서만 나타나며, 일반 PC 화면에는 표시되지 않습니다. 세로·가로 회전에 맞춰 HUD와 버튼 크기 및 안전 영역 여백이 자동으로 바뀝니다.

폭탄과 적 드론의 조준 표시는 화면 중앙에 고정되지 않고 각 대상의 화면상 위치를 따라갑니다. 노란색은 사격 불가, 빨간색은 빗맞춤 보정, 굵은 파란색은 직격 보정 상태입니다. 동시에 여러 대상이 보여도 실제 자동 보정 대상으로 선택된 하나만 빨강·파랑으로 바뀌며, 레이저가 이 선택 대상을 우선 자동 조준합니다. 드론은 190m부터 `AUTO SCAN`으로 추적되고 폭탄보다 넓은 자동 보정 영역을 사용합니다. 빨간 상태에서는 45%, 파란 상태에서는 100% 피해를 받고 피해 숫자가 표시됩니다. 폭탄은 체력이 없으며 빨강이나 파랑 상태에서 한 번 발사하면 즉시 폭발하고, 빗맞춤은 300점·직격은 600점의 기본 점수를 줍니다.

파란 에너지와 황금 에너지는 직접 총으로 쏘지 않습니다. 각각의 넓은 회수 반경을 통과하면 자동으로 낮은 점수가 쌓이며, 플레이어 앞에서 갑자기 나타나지 않도록 새 도시 청크가 준비되는 시점에 함께 배치됩니다.

폭탄은 최소 두 개가 서로 다른 진행 구역에 활성화되며, 파괴된 뒤 1.8~2.8초의 짧은 공백을 두고 현재 진행 방향 102~142m 앞에 보충됩니다. 노란 `CHASE` 표시는 아직 사격 거리 밖이라는 뜻이며, 105m 안으로 접근하면 빨강·파랑 자동 조준 판정을 받을 수 있습니다. 일반·황금 에너지는 새 청크마다 2~4개씩, 전체 최대 34개까지 배치되어 비행 중 꾸준히 만날 수 있습니다.

전투 모드의 초록색 상자 형태 힐팩은 도시 청크에 최대 6개까지 비교적 자주 배치됩니다. 레이저로 자동 조준해 맞히면 즉시 소모되며, 빨간 `GRAZE`는 16 HP, 초록색 직격 표시는 32 HP를 회복합니다. 레이저는 약 88m의 짧은 사거리에서 시작해 레벨마다 피해·연사·자동 조준 사거리가 강화됩니다.

## 스테이지와 아이템

- 첫 스테이지는 12,000점에 종료되고 이후 구간 요구량이 6,000점씩 증가합니다. 누적 목표는 스테이지가 오를수록 넓어지며 스테이지 10까지 이어집니다.
- 하나를 고르면 다음 스테이지로 넘어가며 3초 동안 무적 자동 활공으로 재출격합니다.
- 룰렛 카드를 누르면 해당 카드가 어두워지고 중앙에 전용 확인창이 나타납니다. 선택 또는 교체를 카드 안에서 확정해야 적용되며, 취소하면 바로 다른 카드를 고를 수 있습니다.
- 패시브는 제한 없이 누적됩니다. 공격 아이템은 우클릭 레이저 업그레이드만 등장하며, 장착품은 한 칸만 사용합니다.
- 같은 아이템이 다시 나오면 레벨이 오릅니다. 다른 장착품을 고르면 기존 장착품과 교체됩니다.
- 스테이지 2부터 플레이어를 추격하고 사격하는 체력 보유 드론이 출현하며, 스테이지마다 목표 수가 `3 → 5 → 7 → 9 → 11 → 12`로 증가합니다. 편대는 전방에 집중하되 후방에도 1~2기를 보내 플레이어를 포위합니다.
- 스테이지 4부터 일반 드론보다 약 1.6배 크고 체력 2.45배·공격력 1.75배인 강습 드론이 합류합니다.
- 스테이지 8부터 느린 지상 골렘이 등장해 유도 미사일을 발사하며, 스테이지 8·9·10에서 각각 1·2·3기까지 늘어납니다.
- 스테이지 10의 목표 점수를 채우면 `CITY LIBERATED` 엔딩 연출 뒤 최종 전투 랭킹으로 이동합니다.
- 아이템 이름, 설명, 레벨 수치와 프리뷰 색상은 `src/data/items.csv`에서 수정할 수 있습니다.
- 좌측 보유 장비 HUD는 전체 이름과 분리된 레벨 박스를 표시하며, 하단 속도계에는 이동속도·중력·받는 피해·대시 배수가 함께 표시됩니다.
- 피해 감소·활공·회복·속도·제트팩·피흡 효과가 실제 발동하면 화면 하단에서 속성별 색상의 `PASSIVE TRIGGER` 피드백이 떠오르고 해당 인벤토리 항목이 점등됩니다.
- `혈액 역류 모듈`은 드론 탄환에 맞았을 때 받은 피해의 18%부터 반격 피해로 되돌리며, 실제로 드론에게 준 반격 피해만큼 체력을 회복합니다. 레벨마다 비율이 6%p 증가합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:43127/`을 엽니다.

배포용 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
npm run build
```

## 기술 구성

- TypeScript
- Vite
- Three.js
- Rapier 3D
- GitHub Actions 및 GitHub Pages

게임 BGM과 로프 발사·권취·대시·활공 바람·시간정지 효과음은 `sound/` 폴더의 MP3 자산을 사용합니다. 반복음은 상태 사이에서 페이드 전환되고, 일시정지 메뉴에서는 BGM도 멈춥니다. 총격·명중·폭발은 Web Audio 합성음을 함께 사용합니다.

HUD와 메뉴는 `fonts/kbl/OTF/`의 KBL 로컬 폰트를 사용하며, 외부 웹 폰트 연결 없이 빌드에 포함됩니다. 폭탄 파괴와 플레이어 충돌에는 `폭탄터짐.mp3`와 강화된 파티클·점수 충격 연출이 함께 재생됩니다. 상단 타이머는 타임어택에서 남은 90초를, 전투와 무한 연습에서는 현재 런의 누적 플레이 시간을 표시합니다.
